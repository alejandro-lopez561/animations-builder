# Workspace redesign — architecture and baseline

## Baseline before edits

2026-09-21: 35 tests pass, lint passes. Vite runs on 5185. Browser baseline checked: search Fade Up returns one match; selecting sets fadeUp; editing text updates preview; duplicate creates independent fadeUp-copy. Original state retained on that local origin for comparison.

## Responsibility map

- `useAnimationBuilder`: elements, active, playKey, initial restoration, autosave, importBackup and nextId. addElement/removeElement/duplicate/move/setActive/rename/update/selectPreset/setAppearance/replay are the existing mutation handlers. importProject/exportProject/restoreBackup own JSON and backup operations.
- `project.js`: schema v1, serialize/parse, duplicate and order helpers; `createElement.js`: defaults. These remain unchanged.
- `BuilderPanel`: existing type restrictions, content/file input, custom controls, animation/timing/advanced fields. Reorganized into mounted tab panels, preserving callbacks, bounds and options.
- `PresetSelector`: local search/filter/expansion state; searchPresets.js and data/*.js define real categories, matching, compatibility and preset data. Family quick buttons call the existing category filter.
- `PreviewStage` + `MotionElement`: actual scene, viewport IntersectionObserver, entered state and replay key. Observer/generation code unchanged; toolbar is presentation only.
- `generateScene`, `generateCss`, `specialCss`, `generateKeyframes`, `specialMarkup`, `timing`, `updateAppearance`: CSS/HTML/classes and calculations. Unchanged.
- `CssOutput`: existing clipboard handler and status retained in the drawer, reused by compact Copy CSS bar.
- SCSS modules own each panel. Global tokens/shared controls establish theme. base.scss is an untouched client reference.

## New presentation components

- AppHeader: navigation, theme control and ProjectControls menu.
- ElementsPanel: selection and contextual calls to the existing handlers.
- BuilderPanel: Content / Animation / Timing / Advanced tabs, kept mounted.
- LivePreviewPanel: canvas width and workspace expansion, no configuration changes.
- CssOutput: compact bottom bar and independent code region using its existing copy function.
- DocumentationPage: hash navigation, builder remains mounted.
- useTheme: independent localStorage key, initial system preference; project storage unchanged.

New project uses the existing importProject handler with a version-1 file generated by serializeProject/createElement, only after confirmation; it therefore uses the existing backup mechanism. No alternative scene state or mutation implementation is introduced. Delete and backup restoration also request confirmation in the UI.
